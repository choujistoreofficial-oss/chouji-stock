📱 B. NOKOS (NOMOR KOSONG)

Apa itu Nokos?
Nokos adalah istilah yang biasa digunakan untuk menyebut nomor telepon virtual atau nomor yang disediakan untuk kebutuhan verifikasi akun melalui SMS atau OTP.

Nokos dapat digunakan untuk kebutuhan seperti:

  • Pendaftaran akun tertentu.
  • Verifikasi nomor telepon.
  • Menerima kode OTP apabila layanan mendukung.
  • Kebutuhan pengujian atau penggunaan akun digital yang sesuai ketentuan platform.

Bagaimana cara kerja Nokos?

  1. Pilih layanan atau negara yang tersedia.
  2. Pesan Nokos melalui admin.
  3. Admin membantu proses penyediaan nomor.
  4. Tunggu kode OTP jika tersedia.
  5. Gunakan kode tersebut sesuai kebutuhan layanan.

Perlu diketahui:

  • Tidak semua layanan selalu berhasil mengirimkan OTP.
  • Ketersediaan nomor bergantung pada stok dan layanan.
  • Jangan membagikan kode OTP kepada orang lain.
  • Gunakan nomor sesuai ketentuan platform terkait.

🔎 3. CARA CEK ID TRANSAKSI

Pernah membeli produk tetapi ingin melihat kembali detail pesanan? Tenang! CHOUJI STORE menyediakan fitur CEK TRANSAKSI melalui website.

Apa itu ID Transaksi?
ID Transaksi adalah kode identitas unik yang digunakan untuk mengenali suatu pesanan.

Setiap pesanan yang tercatat memiliki ID transaksi tersendiri. Kode ini berguna untuk membantu pelanggan maupun admin menemukan data pesanan yang dimaksud.

Contoh format ID transaksi Nokos:
CHJ-NKS-20261125-001
Contoh tersebut hanya ilustrasi format ID.

Cara mengecek transaksi:

  1. Buka website resmi CHOUJI STORE.
  2. Cari menu CEK TRANSAKSI.
  3. Masukkan ID Transaksi yang kamu miliki.
  4. Tekan tombol cek atau cari.
  5. Tunggu sistem memproses pencarian.
  6. Periksa informasi pesanan yang ditampilkan.

Jika ID benar dan data pesanan tersedia, sistem akan menampilkan detail transaksi yang sesuai.

Informasi yang dapat diperiksa antara lain:

  • ID Pesanan.
  • Nama atau jenis produk.
  • Nama pesanan.
  • Informasi garansi apabila tersedia.
  • Waktu pembuatan pesanan.
  • Masa berlaku garansi apabila tersedia.
  • Informasi status transaksi sesuai data sistem.

Bagaimana jika ID Transaksi hilang?
Jangan panik. Hubungi admin CHOUJI STORE dan sampaikan informasi yang dapat membantu pencarian pesanan, misalnya nama pemesan dan perkiraan waktu pembelian.

Jangan memberikan password atau kode OTP kepada siapa pun.

🛡️ 4. INFORMASI GARANSI

Beberapa produk mungkin memiliki ketentuan garansi, sedangkan produk lainnya bisa saja tidak memiliki garansi.

Karena itu, sebelum membeli:

  • Periksa keterangan garansi pada produk.
  • Tanyakan kepada admin apabila ketentuannya belum jelas.
  • Simpan ID transaksi sebagai bukti identitas pesanan.
  • Hubungi admin jika mengalami kendala yang termasuk dalam ketentuan garansi.

Penting: Garansi tidak otomatis berlaku untuk seluruh produk. Masa berlaku dan ketentuannya mengikuti informasi yang tercantum pada masing-masing produk atau pesanan.
